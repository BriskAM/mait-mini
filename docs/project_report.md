# GTSRB Traffic-Sign Recognition — Project Report

## Abstract

This report documents an end-to-end, reproducible classification pipeline for the 43-class German Traffic Sign Recognition Benchmark. The project verifies the complete public archive, profiles the data, creates grouped validation data, trains a custom CNN and MobileNetV2, evaluates the official test split, and exposes single-image prediction.

## Dataset and EDA

The Zenodo archive contains 39,209 training images and 12,630 official test images across class IDs 0–42. The published MD5 checksum `7faafd0d78d831c7eb4d555641a83a62` is verified before extraction. EDA outputs are generated by `python scripts/run_eda.py` and include class balance, sample imagery, dimensions, brightness, and color statistics.

## Method

Images are resized and normalized. A grouped validation split reduces leakage from related sequences. Training augmentation applies moderate rotation, translation, zoom, brightness, and contrast changes. The baseline is a compact CNN; the comparison model is MobileNetV2 with optional pretrained ImageNet weights. Early stopping, learning-rate reduction, and best-checkpoint saving are enabled.

## Results

The recorded runs use the full dataset: custom CNN for three epochs and MobileNetV2 for one epoch. Accuracy was 51.75% and 53.09%, respectively; macro F1 was 36.44% and 42.24%. These are demonstration results rather than a maximum-performance claim because the epoch budgets differ.

## Limitations and future work

The classifier expects a cropped sign image and is not a detector or driving system. Future work should use matched longer training, class-aware sampling, calibration, out-of-distribution detection, and an object-detection front end for full scenes.
